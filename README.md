# STAT301 - Diabetes Prediction through Logistic Regression Model

This project was completed in Summer 2024 as part of the 3rd-year course, STAT301: Statistical Modelling for Data Science. The goal was to develop a predictive model using logistic regression to assess the likelihood of diabetes. The Pima Indians Diabetes dataset, which includes patient health indicators, was used to classify individuals as diabetic or non-diabetic.
